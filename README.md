## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Static Dread: The Submarine**. A Windows trainer for managing crew pressure, task decisions, sonar operations, and story-focused gameplay aboard the submarine.

**Target Audience:** Players who want more control over crew management, sonar investigations, stressful decisions, and alternate narrative outcomes while exploring the submarine's Lovecraftian horror.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

- **Freeze Crew Pressure** — Prevents crew-related pressure and madness values from increasing during stressful operations.
- **Unlimited Task Attempts** — Allows repeated task interactions without losing progress from failed or unfavorable outcomes.
- **Crew Discipline Control** — Keeps discipline-related gameplay values stable while you assign duties and manage the crew.

## 📖 Detailed Feature Guide

### Movement & Exploration

Movement is primarily used to explore the submarine and reach interactive areas. The trainer does not add movement abilities because the game's core progression is based on investigation, command interfaces, crew assignments, and story events.

### Tools & Inventory

Static Dread: The Submarine is not built around a conventional loot inventory. Progress centers on crew duties, submarine operations, sonar information, and decisions. Use the trainer during task sequences rather than expecting item duplication controls.

### World & Environment

The game takes place aboard a military submarine trapped beneath the North Atlantic during a Lovecraftian apocalypse. Use sonar-related assistance while investigating contacts, then manage crew responsibilities and make decisions that influence branching paths and endings.

### Combat & Weapons

There is no conventional combat system to enhance. The main threats are handled through investigation, command decisions, crew management, and psychological pressure. Combat-related trainer controls are therefore not included.
